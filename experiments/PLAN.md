**M0 修订 1（2026-09-28，任何 M0 代码运行之前）：DCP 得分改为带原子的 HPD 得分。**
- **原因**：DCP 的得分 |F̂(y) − 0.5| 取的是等尾中心带。原子质量很大时（海冰上 y = 0 占 44%），F̂(0) 可能落在中心带之外，最可能的取值反而被排除；要修正只能做随机化 PIT，预测集也会随之变成随机的。
- **新得分**：s(x, y) = P̂(比 y 更可能的区域)。原子相对 Lebesgue 测度的密度视为无穷大，按质量排在最前；内部按预测密度排序，在 [0,1] 上用 200 格网格计算。
- 预测集 {y : s ≤ q} = 若干原子 ∪ 一段内部 HPD 区域，天然落在 [0,1] 内，并且在给定质量下最短。
- 模型 1b、3、4、5 都改用这个得分。模型 6 仍用 Wu 式分位数残差得分。

**附带判定（不作为 Go 条件）**：
- 模型 4/5 与模型 1b 的差距，衡量纯架构效应（得分相同）。
- 模型 6，以及模型 1 与 1b 的差距，衡量得分效应。

## Gate M0 结果（2026-09-28）：按预注册条件**形式上 GO**，但同得分对照显示混合支撑潜变量在真实数据上**没有**贡献

1. Bucket：模型 4/5 相对模型 1 宽度 −7.2%。

5. Syn-Atom 上 flow 的 CRPS 比 logit-normal 低 4.6%。

## HPD 收敛检查结果（2026-09-28）：**通过**

在同一批检查点（海冰、ResOpsUS，模型 1 和 3 各 8 个种子重训并保存）上，按 G = 200 / 500 / 1000 / 2000 重算：
- 所有得分都满足 |W₂₀₀₀ − W₁₀₀₀| / W₂₀₀₀ < 2%（0.16%–0.98%），覆盖率变化 ≤ 0.0004；G ≥ 1000 时排序不变（3 < 1b < 7 < 1）。
- 模型 3 相对 1b：海冰 −53.4%，ResOpsUS −35.5%；相对截断基线 7：海冰 −74.0%，ResOpsUS −63.4%（均为 G = 2000）。**优势不是网格伪影。**
- 集合都是单段区间，跨度等于 Lebesgue 测度。海冰上平均段数为 0.47，约一半的集合只含原子。

**新发现的问题**：ResOpsUS 上模型 3 的原子包含率是 2.000，也就是每个边界集合都同时包含 {0} 和 {1}，而那里真正落在边界上的目标只有 0.4%。
- 原因：HPD 得分把原子视为密度无穷大、测度为 0，**不论预测质量多小都免费纳入**。
- 所以 ResOpsUS 上的 −35.5% **不可能来自原子**：原子质量太小，分担不了覆盖预算；收益应来自输出头的其他差别，比如加了原子分支后连续部分的拟合方式变了。
- "总是包含两个端点"是一种廉价对冲，Lebesgue 宽度不能反映它的代价。之后必须报告原子的信息量，并设门槛变体。

**结论冻结**：潜变量 MiSCo 停止。下一轮是输出层消融，待预注册：
- A：连续输出 + HPD，π₀ = π₁ = 0
- B：双原子 + HPD，原子免费纳入
- C：双原子 + HPD，原子质量低于门槛 τ 时不纳入
- D：双原子头训练，评估时丢弃原子分支
- E：现有方法基线

## 输出层消融 Gate O1：预注册（2026-09-28，任何 O1 结果之前）

**三个研究问题**：
- **RQ1**：免费原子造成的退化是否真实存在？（B 对比 C）
- **RQ2**：收益来自预测时对原子的利用，还是来自混合参数化训练出的连续部分？（B、D、A 三者对比）
- **RQ3**：双边界、原子感知的 conformal 方法，是否优于现有的单边界方法和连续有界方法？（E1–E5）

**数据**（8 个种子，data_seed 随种子变化）：
- 海冰、ResOpsUS（发现数据）
- **Syn-OutAtom（新增，受控）**：静态潜变量 h ∈ [0,1]²（与 Syn-Atom 相同的观测模型）；y 的分布为 π₀(h)δ₀ + π₁(h)δ₁ + π_c(h)·TN(g(h), 0.05²)，其中 π₀ = 0.35·σ(4(0.3 − h₁))，π₁ = 0.25·σ(4(h₂ − 0.7))。两种原子概率已知且随 x 变化，用于检验原子精度和门控是否正确。

**方法**（A–D 以及 E1、E4、E5 都在同一批检查点上只换预测阶段的构造，属于严格的同网络对照）：

| B | 模型 3（双原子头） | 原子免费纳入的 HPD（即当前的模型 3） |
| C | 模型 3 | 门控原子 HPD（硬门控）：若 π̂ⱼ(x) < τ，原子 j 的得分设为 +∞，不进入集合 |
| D | 模型 3 | 预测时令 π₀ = π₁ = 0，只用归一化后的连续部分做 HPD |

- 海冰、ResOpsUS 上直接用已存的 m0_rerun 检查点（模型 1、3 各 8 个种子）；Syn-OutAtom 新训模型 1、3 并保存检查点。
- **E4 / E5 待补**：必须按零膨胀 CP 原文（arXiv 2605.04219）的算法实现：分类阈值由超参数 r 在验证数据上按预测概率分位数生成，并调整非零分支的覆盖水平。算法细节待读原文后逐条写入本节并提交，**之前不得运行 E4/E5 的任何代码**。

**τ 的选择（C）**：
- 候选 τ ∈ {0.01, 0.05, 0.10}。
- **不用正式的校准集或测试集来选**：否则同一份校准数据会被用两次，破坏 split conformal 的有限样本覆盖。
- 做法：把训练时留出的验证集（训练集的 10%，按种子固定划分）再按固定置换对半分。前半做 Mondrian 校准（观测分组、ε = 0.05），后半计算 J(τ) = 边界组平均 [μ(C) + λ_A · N_atom(C)]。
- 后半的边际覆盖率 < 0.88 的 τ 不参与选择；在其余 τ 中取 J 最小的。
- **λ_A 主值预先固定为 0.05**，即一个原子的信息代价相当于长度 0.05 的区间；另外报告 λ_A ∈ {0.01, 0.10} 时选出的 τ 与结果，作为敏感性分析，不得事后更换主值。

**指标**（以观测分组、ε = 0.05 的边界组为主）：
- 连续体积 μ(C) = Σ|I_k|
- 原子数 N_atom = |C ∩ {0,1}|，以及原子包含率
- **模糊度** A_λ(C) = μ(C) + λ·N_atom，λ ∈ {0.01, 0.05, 0.10}，主值 0.05
- **原子精度**：被纳入的原子中恰好等于 Y 的比例（按单元汇总后求比例）
- 边际覆盖率、边界组覆盖率
- Syn-OutAtom 上另报原子概率 ECE（有真值）

**Gate O1 条件**（8 个种子，配对 Wilcoxon，α = 0.05）：
1. **海冰**：B、C、D 中至少一种在 μ 上显著小于 A，覆盖率在 0.90 ± 0.02 之内，且其 A₀.₀₅ 不显著大于 A 的 A₀.₀₅。
2. **ResOpsUS（解释规则，不是通过/失败）**：若 D 保留了 B 相对 A 的收益的 ≥ 50%，则论文中该收益**不得归因于原子**，只能归因于训练阶段的混合参数化。
3. **有效效率收益的定义**：μ 显著减小，同时 A₀.₀₅ 不显著增大，且（在带原子的方法之间比较时）原子精度不显著下降。只减小 μ、却靠塞入原子来实现的，不计为收益。
4. **E5 必须在至少一个双边界场景（海冰或 Syn-OutAtom）上，A₀.₀₅ 显著小于 E4，且覆盖率达标。** 否则"双边界"不构成贡献。（待 E4/E5 规范补齐后生效。）
5. 所有比较用 8 个种子，data_seed 独立变化。

**以后可能扩展（第一轮不跑）**：校准式门控，即 j ∈ C 当且仅当原子得分 ≤ q_atom。

### O1 补充（2026-09-28，任何 O1 代码运行之前）

**E4：CPCI，严格按原文**（arXiv 2605.04219；算法由用户核对原文后提供）：
- 分类器输出 p̂(x) ≈ P(Y ≠ 0 | x)。在我们的双原子头上取 p̂ = 1 − π̂₀。
- 回归只针对 Y > 0，**包括 y = 1 这个原子**：f̂(x) = E[Y | Y > 0] = (π̂₁·1 + π̂_c·E_TN)/(π̂₁ + π̂_c)。E4 是单边界方法，y = 1 并入非零分支。
- 数据：
  - D_train：训练（同一个模型 3 检查点）；
  - D_val：训练时留出的 10% 验证集，用来选 r、估计 β。这份数据也参与过早停，属于轻度复用，如实注明；
  - D_cal 按固定置换对半分为 D_cal,1 和 D_cal,2；
  - 测试集只评估一次。
- α_r = 分位数({p̂(xᵢ) : D_cal,1} ∪ {1}, r)。
- β̂_r = 在 D_val 上，被预测为零（p̂ ≤ α_r）的样本中真正为零的比例。
- γ_r = max{0, min[1, (0.90 − r·β̂_r)/(1 − r)]}。
- q_r = 分位数({Sᵢ = |yᵢ − f̂(xᵢ)| : D_cal,2 中 p̂ > α_r} ∪ {+∞}, γ_r)。有限样本约定：取 ⌈γ_r(n + 1)⌉ 阶的顺序统计量，与主流程一致。
- 预测集：p̂ ≤ α_r 时为 {0}，否则为 [f̂ − q_r, f̂ + q_r]。**不允许 {0} ∪ I。**
- r 的网格：{0, 0.05, …, 0.95}；在 D_val 上选使平均长度 2(1 − r)·q_r 最小的 r（q_r 用 D_val 自身的分位数估计，不用 D_cal）。
- 报告两种宽度：原始宽度和可行测度 |C ∩ [0,1]|，**主指标用可行测度**。
- **Mondrian**：原文是边际版本。为与其他方法可比，r 的选择与 α_r、q_r 的计算都**在观测分组的边界组内**进行，这是对原文的适配，需在论文中注明。

**E5：双边界推广（前瞻性提出，不是 CPCI 原文）**：三个类别 Y = 0、0 < Y < 1、Y = 1；按 CPCI 的覆盖分解，覆盖预算写成
0.90 = r₀β₀ + r₁β₁ + (1 − r₀ − r₁)γ，
所以连续分支的目标覆盖 γ = clip[(0.90 − r₀β₀ − r₁β₁)/(1 − r₀ − r₁), 0, 1]。
- 预测集只允许五种形态：{0}、[0, b]、[a, b]、[a, 1]、{1}，**不允许 {0} ∪ I ∪ {1}**。
- 两个原子同时满足条件时，取标准化裕度 m_j = (p̂_j − t_j)/(1 − t_j) 更大的那个，**不输出 {0, 1}**。
- **在以下四项全部写定之前，不实现 E5**：
  1. (r₀, r₁) 的候选网格；
  2. 验证目标；
  3. 双原子冲突规则的最终形式；
  4. 连续分支 conformal 分位数的有限样本约定。
- 按研究效率原则：如果 A–D 显示原子路由没有独立收益，就不开发 E5。

**O1 实现记录（2026-09-28）**：
- HPD 集合用 G = 1000 格（收敛检查表明超过 1000 后变化 < 1%）。
- 冒烟测试时打印出了海冰 seed 0 上各方法的宽度，也就是说正式运行前看到了 1/24 个（数据集，种子）组合的结果。之后没有据此修改任何代码或判据，如实注明。
- 单元测试确认：门控过度（校准集中超过 10% 的目标落在被门控的原子上）时，conformal 分位数为 +∞，预测集退化为整个空间。这是 conformal 的正确行为，也说明 τ 选择中"后半覆盖率 ≥ 0.88"这条约束是必要的。

**E2 / E3 的复用**：海冰和 ResOpsUS 上的 CQR（模型 2）、Beta + Wu（模型 6）在 Gate M0 中已按完全相同的协议运行（data_seed = seed，同样的划分），直接复用；可行测度 CQR 取 M0 中的 "2_clipped"。只在 Syn-OutAtom 上新训模型 1、2、3、6（8 个种子，保存检查点）。

## Gate O1 结果（2026-09-28）：条件 1 **不通过**

全部运行完成（Syn-OutAtom 训练 32 次，无重试）。原始输出见 `results/o1_verdict.txt` 与 `results/o1.json`。

| 数据集 | A（连续 HPD） | B（免费原子） | C（门控原子） | D（丢弃原子分支） | E4（CPCI） |
|---|---|---|---|---|---|
| 海冰 μ / A₀.₀₅ | 0.032 / 0.032 | 0.015 / **0.089** | 0.015 / **0.065** | 0.740 / 0.740 | 0.028 / 0.054 |
| ResOpsUS μ / A₀.₀₅ | 0.036 / 0.036 | 0.024 / 0.124 | **0.395** / 0.435 | **0.024** / 0.024 | 0.047 / 0.049 |
| Syn-OutAtom μ / A₀.₀₅ | 0.852 / 0.852 | **0.541 / 0.641** | **0.618 / 0.696** | 0.982 / 0.982 | 0.898 / 0.902 |

原子精度：海冰 B 0.57、C 0.84、E4 0.94；ResOpsUS B 0.03；Syn-OutAtom B 0.11、C 0.14。覆盖率全部在 0.88–0.92 之内，只有 E3 在海冰上为 0.999（退化）。

**RQ1（免费原子退化）：确认存在。**
- 海冰上 B 平均每个集合含 1.47 个原子，精度只有 0.57；门控后的 C 降到 1.00 个原子，精度 0.84，μ 几乎不变。
- 但按主模糊度 A₀.₀₅，B 和 C 都比 A 显著更差（+176%、+103%，p = 0.008）。
- **条件 1 不成立：海冰上的 μ 减半，完全是靠把原子放进集合换来的。** 按预注册的原子成本 λ = 0.05，这不算有效的效率收益。
- 敏感性：λ = 0.01 时，C 的 A = 0.0251，比 A 的 0.0321 小 22%。结论依赖 λ，但主值是预先固定的，不能更换。

**RQ2（收益来源）：ResOpsUS 上 D 保留了 B 收益的 97%。** 按预注册的解释规则，这部分收益**不能归因于原子**，只能归因于训练阶段的混合参数化。D 相对 A 窄 33.6%，但 p = 0.109，8 个种子下不显著。
- C 在 ResOpsUS 上退化（μ = 0.39）：边界组很小，个别被门控掉的原子目标就让组内分位数变成 +∞，集合变成整个空间。

**RQ3（与现有方法对比）**：
- **原子路由只在 Syn-OutAtom 上带来有效收益**：B 的 μ −36.5%、A₀.₀₅ −24.7%，C 为 −27.5% / −18.3%，p 都是 0.008。那里的原子真实存在、且随 x 变化，D 比 A 更差（+15%），说明收益确实来自原子。原子概率估计的 MAE 为 0.040，ECE 为 0.019。
- 但原子精度很低（0.11–0.14），集合里的原子多数是"没打中"的。
- CPCI（E4）在三个数据集上都没有显著优于 A；它在海冰上的原子精度最高（0.94），但模糊度仍比 A 高 69%。
- CQR（E2）和 Beta + Wu（E3）在海冰和 Syn-OutAtom 上都很差。
- 条件 4（E5 对比 E4）：E5 未实现，待定。

**结论**：
- 真实数据上，**原子感知的集合没有带来有效的效率收益**：海冰上的收益靠原子换来，ResOpsUS 上的收益与原子无关。
- 只在受控合成数据上，原子路由才有独立价值。
- ResOpsUS 上"训练时加入原子分支、预测时丢弃"让区间变窄的现象值得注意，但目前不显著。

### Gate O1.5：寻找真实数据（预注册，查看任何候选数据的模型结果之前）

一个候选数据集必须同时满足下面 6 条，**只统计数据本身的性质，不训练模型**：
1. P(Y = 0) ≥ 0.05，且 P(Y = 1) ≥ 0.05；两个原子都不是极小概率。
2. 0 和 1 都是有语义的真实状态（比如完全晴空 / 全云覆盖），**不是预处理截断的产物**。
3. 内部 (0,1) 的质量 ≥ 0.2，并且有实际宽度：内部条件分布的典型 90% 区间宽度 ≥ 0.1，用一个简单的最近邻条件估计粗略判断。这是为了避免出现海冰那种"区间极窄，结论完全由原子成本支配"的情况。
4. 原子概率随 X 明显变化：用训练集上的简单逻辑回归预测 1{Y = 0} 和 1{Y = 1}，AUC ≥ 0.7。
5. 样本足以严格拆分训练、验证、校准（再对半分）和测试；单元之间能构造出近似可交换的结构。
6. 公开可获取，许可证清楚。

- **找到 ≥ 1 个**（最好 2 个，且与海冰性质不同）：冻结 E5 规范，把评价升级为下面的 λ 曲线，然后实现 E5；新数据作为真正的留出确认。

**E5 修订 1（2026-09-29，开发自检中发现，任何 ERA5 运行之前）：增加可行性约束。**
- 问题：单元测试中，最小最大遗憾选中了 (r₀, r₁) = (0.2, 0.3)。被路由的原子精度很低（β̂₀ = 0.36，β̂₁ = 0.16），覆盖预算要求连续分支承担超过 100% 的覆盖，γ 只能截断为 1，q = +∞，**实际总覆盖约 0.67**。该配置之所以被选中，是因为 q = +∞ 的区间截断到 [0,1] 后测度只有 1，截断测度掩盖了无穷代价，又是一次免费午餐。
- 修正：只有**未截断的 γ ≤ 1 且验证集上 q 有限**的候选才可行；(0, 0) 即纯连续 conformal，永远可行。
- E4（CPCI 原版）没有这个问题：它按未截断长度 2(1 − r)q 选 r，q = +∞ 时长度为无穷，不会被选中。
- 修正后在同一测试中：35 个候选里 12 个可行，选中 (0.10, 0.025)，覆盖率 0.885。

### E5 规范冻结（2026-09-28；只依据发现数据，ERA5 云量与 Snow_cci 保持留出）

1. **(r₀, r₁) 网格**：r_j ∈ {0, 0.025, 0.05, 0.10, 0.20, 0.30}，且 r₀ + r₁ ≤ 0.5。
2. **验证目标：最小最大遗憾**。在 λ 网格 Λ = {0, 0.01, …, 0.10} 上，选使 max_{λ∈Λ} [A_λ(配置) − min_配置' A_λ(配置')] 最小的 (r₀, r₁)。
   - **不用 A_λ 的面积平均**：A_λ 对 λ 是线性的，在 [0, 0.10] 上等权积分恰好等于 A₀.₀₅，又退回单点准则。
   - λ\* = (μ_cont − μ_E5)/(N_atom,E5 − N_atom,cont)（分母为正时）只作为描述量报告。
3. **路由与冲突规则**：
   - p̂_j 为模型 3 原子头给出的原子 j 的概率（混合平均）。阈值 t_j 取 D_cal,1 上 p̂_j 的 (1 − r_j) 分位数（r_j = 0 时 t_j = +∞），p̂_j ≥ t_j 时路由到原子 j。
   - 两个原子同时满足时，取标准化裕度 (p̂_j − t_j)/(1 − t_j) 更大者；**完全相等时进入连续分支**；不随机处理，**不输出 {0, 1}**。
4. **连续分支**：
   - 预测中心 f̂ = E[Y | x]，即模型 3 的完整混合均值；得分 S = |y − f̂|；区间 [f̂ − q, f̂ + q] ∩ [0,1]，所以形态自然为 [0, b]、[a, b]、[a, 1]。
   - 覆盖预算 γ = clip_[0,1][(0.90 − r₀β̂₀ − r₁β̂₁)/(1 − r₀ − r₁)]，其中 β̂_j 为 D_val 上被路由到原子 j 的样本中确实为 j 的比例（没有样本被路由时取 0）。
   - **有限样本约定**：在 D_cal,2 中未被路由的 n_c 个样本上，k = ⌈(n_c + 1)γ⌉；k > n_c 时 q = +∞，否则 q = S_(k)。
5. **数据划分**：与 E4 相同（D_val 选 r 并估计 β；D_cal 对半分，前半定阈值，后半算 q）。在观测分组内分别执行（Mondrian 适配）。
6. **计数口径**：N_atom 只计单点集 {0}、{1}；触及边界的闭区间，其代价已计入 μ。
7. **报告**：每个候选 (r₀, r₁) 的有效校准量 n_c（不据此剔除候选）、覆盖率、μ、N_atom、原子精度、完整的 A_λ 曲线与 λ\*。
8. **覆盖性质（如实说明）**：β̂ 在 D_val 上估计，因此与 CPCI 一样，覆盖保证是近似的（依赖 β̂ 的估计误差），不是严格的有限样本保证。
9. **研究者设计 vs 方法流程**：网格、准则、规则只在发现数据上确定；方法自带的 (r₀, r₁) 选择是算法的一部分，在留出数据上用该数据集自己的验证集执行。

### 评价体系升级：λ 曲线与 λ\*

- 模糊度 A_λ(C) = μ(C) + λ·N_atom(C)，λ ∈ [0, λ_max]。主对象从单点 λ = 0.05 改为 **ΔA_λ 随 λ 变化的整条曲线**。
- 交点：λ\* = (μ_cont − μ_atom)/(N_atom − N_cont)（分母为正时）。原子感知方法对一切 λ < λ\* 占优。
- O1 中 λ = 0.05 的结果保留为历史预注册结论，不作废，也不改写。
- 对 O1 已有结果计算 λ\*，**只作探索性描述，不能作为确认证据**。

# 研究计划（2026-09-27 起改投 TNNLS；原 ICML 计划保留在下方作为记录）

## 新方向：ASCL（Adaptive Support-Constrained Latent Learning）

**核心问题**：在有物理边界的学习任务中，什么时候应该对潜变量施加 support 约束，约束应该多强，以及约束如何影响表示、校准和 conformal 不确定性。

**数据的角色（关键）**：
- 已完成的 5 个预注册数据集（Syn-Full、Syn-Extreme、海冰、Bucket、ResOpsUS）定位为**发现/诊断集**。新方法是在看过这些数据之后设计的，所以它们**不能**作为新方法的最终验证。
- 另设**留出的确认集**：方法冻结之后才能接触，并单独预注册。

**阶段与闸门**：
- **Stage 0**：冻结旧证据，把 600 次运行结果和本计划提交到 git。
- **Stage 1**：理论重构。
  - 支撑–表达力权衡：失配 M(x) 对比表示受限 E_Q(x)。
  - 分位数–尺度传播：R_q、R_σ。
  - 定理 5 降级为"分位数通道的充分条件"。
- **Stage 2**：受控合成实验，画相图（泄漏 M × 所需后验标准差 C）。先确认规律确实存在。
- **Stage 3**：ASCL 原型，要求 λ = 0 时退化为 Gaussian、λ = 1 时退化为严格有界。
- **Gate 1**：在 Syn-Full、Syn-Extreme、Bucket、ResOpsUS 中至少 3/4 满足 W_ASCL ≤ min(W_G, W_B) + 2%，覆盖率不下降，且不出现 ResOpsUS 那样的灾难性失败。**不通过就暂停方法路线。**
- **Gate 2**：在相图上，ASCL 在 Gaussian 占优区和有界占优区都能接近两者中的较好者。
- **Gate 3**：冻结方法，之后才允许接触留出的真实数据；确认集的 hypotheses、指标、数据集事先预注册；此后不得因为结果修改模型。
- **Stage 7–8**：消融、鲁棒性、复杂度分析，然后撰写论文。

### 框架与闸门调整（2026-09-27，根据评审意见）

**三项代价**：约束的净效果 = 支撑失配代价 + 分布族近似代价 + 训练适应代价。第三项不要求完整的理论化，但必须用实验隔离出来（Gate B）。

**表示代价 E_Q 不限于可达性**：分别用 KL、Wasserstein、矩差异度量，再看哪一个与下游区间变宽最相关。要区分四个层次：支撑可行、均值–方差可行、完整形状近似、优化可达。

**数据角色（最终版）**：
- 旧 5 个数据集 + 相图网格 = **发现/开发证据**。ASCL 可以参考它们来设计，但它们不能作为 ASCL 的验证。
- 新的真实数据 = **留出的确认证据**。

**p_b = 0 的处理**：图中标 NA，不标 0；只报告全局/次要指标；不重新定义这一列来制造边界样本。如果以后需要接近零的条件（例如 p_b = 0.01），只能作为明确标注的后续实验，不能替换原设计。

**闸门**：
- **Gate A（机制有效）**：相图呈现稳定的 regime 依赖（按 Stage 2 事先写定的判据）。
- **Gate B（反事实有效）**：反事实交换实验能解释独立训练模型之间差距的相当一部分（判据见下）。
- **Gate C（ASCL 原型）**：只有 A、B 都通过才进入。第一目标是 W_ASCL − W_oracle 足够小且覆盖率不降，其中 W_oracle = min(W_G, W_B)。

A 或 B 不通过时，不硬上 ASCL；应先研究训练适应，或寻找真正的控制变量。

### Gate B：反事实交换实验，预先写定（2026-09-27，运行之前）

- **数据**：5 个发现数据集；TN-hetero、原始输入配置；种子 0–9 的已存检查点（不重新训练）。
- **有界分布族**：trunc_gaussian、logit_normal、beta、kumaraswamy，四个**全部报告**。
- **为什么可以交换**：所有模型的观测模型已知，都是 x_T ~ TN(h_T, σ)，这把潜变量坐标锚定在物理坐标上。因此不同模型的编码器和解码器处在同一个潜变量空间里，可以互换。

**五个组合**（每个组合都在校准集上重新做 conformal 校准）：

| 组合 | 编码器（后验） | 解码器 |
|---|---|---|
| (a) | Gaussian 模型的编码器 q^G | Gaussian 模型的解码器 |
| (b) | 有界模型的编码器 q^B | 有界模型的解码器 |
| (c) | q^B | Gaussian 模型的解码器（同一解码器，只换后验） |
| (d) | q^G | 有界模型的解码器（同一后验，只换解码器） |
| (e) | q* = q^G 截断到 M（理论参考） | Gaussian 模型的解码器 |

**指标**：观测分组，ε = 0.05，原始宽度 W。

**2×2 分解**：观测差距 (a) − (b) 恰好等于后验主效应与解码器主效应之和。
- 后验主效应 = ½[(a − c) + (d − b)]
- 解码器主效应 = ½[(a − d) + (c − b)]
- 交互项 = ½[(a − c) − (d − b)]（只用于诊断，不进入差距的分解）

**通过判据**：对某个分布族，统计"观测差距不可忽略（|log(W_a/W_b)| > 0.02）、后验主效应与观测差距同号、且 |后验主效应| ≥ 0.5 |观测差距|"的数据集个数。个数 ≥ 3/5 时，记该分布族通过。**4 个分布族中至少 3 个通过，Gate B 才算通过。**

**实现细节（2026-09-27，在任何 Gate B 结果之前）**：每个后验取 S = 128 个样本。自检发现 S = 32 时的 Monte Carlo 噪声约为宽度的 1.4%，与要检测的效应（4–8%）量级接近。

**次要指标**：理论反事实 (a) − (e) 的符号是否与观测差距一致。这检验命题 A–D 所描述的纯支撑限制效应。

**Gate B 不通过的含义**：差距主要来自解码器或训练适应。ASCL 这时就不能只改潜变量分布族，必须同时控制解码器的不确定性。

**更正（2026-09-29）**：下文 Gate B 中"200/200"的计数有误。(a) 与 (e) 只用 Gaussian 检查点，每个种子的 4 个有界族行是同一对值的重复，**独立证据为 50/50 个（种子，数据集）组合**。结论方向不变，计数以此为准。

### Gate B 结果（2026-09-27）：按预注册判据**通过**（3/4 个分布族），但有两条重要保留

| 分布族 | 通过的数据集 | 结论 |
|---|---|---|
| Beta | 5/5 | 通过 |
| Logit-normal | 4/5 | 通过 |
| Kumaraswamy | 4/5（ResOpsUS 未通过：后验份额 27%，差距主要来自解码器） | 通过 |
| 截断 Gaussian | 2/5 | 不通过 |

- **主结论**：在大多数数据集上，同一个解码器下只换后验（后验主效应），就能再现观测差距的符号和一半以上的幅度。**分布族学到的后验本身，是差距的主要载体。**
- **保留 1：交互项很大**，海冰上尤其如此（−0.07 到 −0.15，比观测差距本身大一个量级）。交叉组合 (c)、(d) 的效果很差：解码器遇到的是训练时没见过的后验。所以在海冰上，2×2 主效应分解不可解释，"后验份额 500%"之类的数字没有实际含义。论文中必须报告交互项，并说明海冰上的分解不成立。
- **保留 2（最重要）：理论反事实全部反向。** 用同一个 Gaussian 解码器，把 Gaussian 后验截断到可行域 M 得到 q*，**200/200 个（种子，分布族）组合中宽度都变大**：Syn-Full 0.210 → 0.220，Syn-Extreme 0.134 → 0.144，海冰 0.070 → 0.166，Bucket 0.223 → 0.242，ResOpsUS 0.053 → 0.056。
  - 含义："去掉泄漏"本身从来不会让区间变窄。解码器是在含泄漏样本的后验上训练的，已经适应了泄漏；突然移除，反而破坏了校准。
  - 所以有界模型的收益来自**独立学到的后验和解码器组合**，而不是"支撑限制"这一操作本身。命题 A–D 所刻画的纯支撑限制机制**没有**得到实验支持。
  - **这是"训练适应代价"真实存在、且量级很大的直接证据**。它应当成为新理论的核心，而不是附注。
- 覆盖率在所有组合下都约为 0.89–0.905，交换不会破坏校准有效性（conformal 在校准集上重新校准）。
- **对 ASCL 设计的含义**：只调整潜变量的约束强度是不够的，必须和解码器一起训练，让解码器适应约束后的后验。任何"事后把 Gaussian 后验约束一下"的做法，都会像 (e) 一样变差。

### Bucket 消融阶梯：预注册（2026-09-28，运行之前）

**目的**：找出是什么让 Bucket 的符号与 Syn-Full / Syn-Extreme 相反。Bucket 生成器完全可控，把它一步步退化到类 Syn-Full 的设定，**每一步只改变一个主要因素，而且逐级累积**：

| 级 | 相对上一级的改变 |
|---|---|
| B0 | 原 Bucket：按站点划分（训练与校准/测试的站点不重叠）；每单元的参数各不相同；真实 Daymet 驱动，且驱动出现在观测中；d = 2；目标 = 次日上层含水量 |
| B1 | **去掉站点偏移**：训练、校准、测试都从全部 120 个站点中独立同分布抽取 |
| B2 | **去掉参数异质性**：所有单元共用一组参数 θ₀（各参数取值区间的中点） |
| B3 | **去掉外生驱动**：降水改为从全体日降水中独立同分布抽取（打乱时间和站点，只保留边际分布），PET 取全局均值常数；驱动不再出现在观测中，动态变为 x_{t+1} = f(x_t) + 噪声 |
| B4 | **降到一维**：只保留上层（d = 1），下渗的水直接离开系统 |
| B5 | **目标改为与 Syn-Full 同构**：y = g(h_T)，g 为固定的随机正弦映射，加 TN 噪声 0.03，替代"次日状态" |

**固定不变**：模型、训练预算、TN-hetero 解码器、评估协议；data_seed 随种子变化；B0 也在同一协议下重跑。
- 分布族：gaussian、logit_normal、kumaraswamy。
- 每级 5 个种子，共 6 级 × 3 族 × 5 种子 = 90 次运行。

**每级记录的指标**：
- ΔW：主指标为观测分组、ε = 0.05、原始宽度；次要为 oracle 分组。
- R_q、R_σ，按宽度分解计算。
- Gaussian 泄漏 L。
- 验证集 y 的对数似然（NLL）和重构项。
- 测试集 RMSE。
- 累积效应 Δ_k = ΔW(B_k) − ΔW(B_{k−1})，按各级间的增量报告，不只寻找"哪一级翻转"。

**Gate A2 通过判据**：以下三条同时满足才算通过（"因素改变 → 机制改变 → 符号改变"三环齐全）：
1. **符号反转**：至少一个单因素级 B_k 相对 B_{k−1} 出现稳定的符号反转，即 ΔW 的符号在 ≥ 4/5 个种子上与上一级相反。logit-normal 和 Kumaraswamy **两族都要满足**，每族分别报告。
2. **机制改变**：同一级在以下中介量中至少有一个发生对应的结构变化：
   - log R_q 或 log R_σ 变号，或幅度变化超过 50%；
   - 拟合质量差距（NLL 或重构项的 G − B 差值）变号；
   - 对该级做编码器/解码器交换实验时，交互项或后验主效应变号。
3. 不能只是宽度翻转而中介量没有任何变化。

**已知混杂（2026-09-28，查看任何阶梯结果之前记录）**：各级数据的统计量（seed 0 测试集）如下：

| 级 | p_exact | ε = 0.05 边界比例 |
|---|---|---|
| B0 | 0.265 | 0.52 |
| B1 | 0.268 | 0.50 |
| B2 | 0.254 | 0.46 |
| B3 | 0.047 | 0.34 |
| B4 | 0.046 | 0.16 |
| B5 | 0.046 | 0.16 |

- B3（独立同分布降水）消除了真实天气中的长旱期，p_exact 从 0.25 降到 0.05。
- **因此，B3 同时改变了"外生驱动"和"边界原子质量"两个因素。** 如果翻转出现在 B3，无法区分是哪一个导致的，必须如实报告为混杂，并需要后续实验拆开。设计本身不修改。
- B4 降到一维后，边界比例从 0.34 降到 0.16，也同时改变了维度和边界比例。
- B0 已验证与原 Bucket 数据逐位一致。

**若是多级累积**（没有单级满足判据 1，但累积 Δ_k 使符号逐步翻转）：如实报告为"反转由多个结构偏离累积造成，而非单一标量 regime 变量"。

**决策**：
- **B1 翻转**：优先转向"感知偏移的后验–解码器联合适应"。
- **B2–B4 翻转**：围绕对应的结构因素重建理论。
- **只在 B5 才翻转，或一路不翻转**：原合成现象缺乏真实任务外推性，停止 ASCL，收敛为诊断性 / 负结果论文。

### Bucket 消融阶梯结果（2026-09-28）：Gate A2 **不通过**，按决策树停止 ASCL

90/90 次运行全部完成，无重试。分析脚本 `scripts/analyze_ladder.py` 在结果出现之前已提交。

主指标（观测分组、ε = 0.05、原始宽度），ΔW = (W_G − W_B)/W_G，正值 = 有界分布更窄；括号内为 5 个种子中 ΔW > 0 的个数：

| 级 | logit-normal | Kumaraswamy | Gaussian 泄漏 L |
|---|---|---|---|
| B0 原 Bucket | −9.2%（0/5） | −7.0%（0/5） | 0.275 |
| B1 去站点偏移 | −4.2%（1/5） | −4.4%（0/5） | 0.284 |
| B2 去参数异质性 | −5.2%（2/5） | −0.6%（4/5） | 0.275 |
| B3 去外生驱动（与 p_exact 下降混杂） | +1.8%（4/5） | +1.3%（2/5） | 0.187 |
| B4 降为一维 | −3.5%（1/5） | −7.2%（1/5） | 0.069 |
| B5 目标与 Syn-Full 同构 | **−10.2%（0/5）** | **−26.4%（0/5）** | 0.068 |

- **判据 1 不成立**：没有任何一级在两个分布族上都出现稳定的单级反转。所谓单族内的"翻转"（logit-normal 在 B4、Kumaraswamy 在 B2）只出现在一个族里，而且落在接近零的区间（−0.6% 到 +1.8%），不稳定。
- **也不是多级累积趋向 Syn-Full**：差距从 B0 的 −7% 到 −9%，在 B3 附近回到 0 左右，之后又变得更负。**退化到最接近 Syn-Full 的 B5 时，有界分布反而明显更差**（−10%、−26%）。oracle 分组（次要指标）下的模式相同，只有 logit-normal 在 B5 为 +4.2%。
- B1（去站点偏移）让差距缩小 2.6–5.0 个百分点，只有部分作用；站点偏移**不是**反转的主要原因。
- **判据 2 设计过弱（如实记录）**：几乎每一级都有中介量"发生变化"，因为 50% 幅度变化或变号的门槛对接近零的量太容易达到。这条判据没有区分力，以后不能再用这种形式。
- **含义**：Syn-Full / Syn-Extreme 上"有界分布更好"的结果，在一个结构上已经很接近它们的 Bucket 变体（B5：一维、无驱动、无偏移、同构目标）上**不能复现**。剩下的差别主要在动态本身：线性 AR 加 regime 加截断，对比水量平衡的非线性动态。也就是说，原来的正面结果很可能**是特定合成生成器的性质，不具有真实任务外推性**。

**按预注册决策树**："一路不翻转，或只在最后才翻转 → 停止 ASCL，收敛为诊断性 / 负结果论文"。本结果属于"一路不翻转"，而且最接近合成设定的一端反向更强，所以**停止 ASCL 路线**。

已被证据支持、可以写进诊断性论文的内容：
1. 预注册的五数据集证伪（第 5 节）。
2. 命题 3（单侧划分误差）在全部数据集上严格成立。
3. 宽度的分位数–尺度分解，以及"分位数收缩"现象（五个数据集中四个出现 q^G < q*）。
4. Gate B：单纯截断支撑，在 200/200 个组合中都让区间变宽；有界模型的收益来自联合训练得到的后验–解码器对。
5. 表示几何：Kumaraswamy 在窄后验下的结构性缺陷。
6. 相图与本阶梯：有界约束的收益强烈依赖数据生成过程，而且不能由 (p_exact, C, L)、站点偏移、参数异质性等单一结构因素解释。

### Gate A 结果（2026-09-27）：按预注册判据**形式上通过**；但预期大部分不成立，外部效度不足

900 次运行全部完成（10 次原生崩溃，重试后都成功）。图：`figures/phase_diagram.png`；汇总：`results/phase_summary.json`。

**判据检验**：
- 四个分布族中，符号一致的格子分别有 24、22、21、24 个（每族 30 格），明显连成片。
- 两个区域：
  - C ≤ 0.05：有界分布占优，大部分格子为 + 号，幅度 +3% 到 +57%，峰值在 C = 0.02、p_b = 0.4–0.6。
  - C ≥ 0.1：差距在 ±4% 以内，略偏向 Gaussian，符号多数不一致。
- 沿 C 方向只有一次符号转变；沿 p_b 方向，只有 p_b = 0.1 这一列的部分格子为 −（Beta 和 Kumaraswamy 在 C = 0.005，截断 Gaussian 在 C = 0.02），其余为 +。
- 结论：**regime 结构存在，Gate A 形式上通过。**

**与预注册预期对照**：
- "p_b 大、C 大时有界分布占优"：**不成立**。C 大时差距消失。原因是 C ≥ 0.1 时观测噪声 σ_obs = C·√50 ≥ 0.7，数据几乎不含信息，两种模型都由先验主导。
- "C 小、p_b 小时 Gaussian 占优"：**部分成立**，只在 p_b = 0.1、C = 0.005 附近，而且 logit-normal 例外。
- "Kumaraswamy 在 C 小时失败最严重"：**部分成立**，只在 p_b = 0.1 时出现（−22%），其余格子与其他分布族相当。
- **主导变量是 C，不是 p_b。**

**设计缺陷（如实记录）**：
- 实测泄漏 M 没有被 p_b 有效控制：C ≥ 0.1 时，不论 p_b 取多少，M 都约为 0.083；整个网格的 M 只覆盖 0.05–0.33。
- **ResOpsUS 所在的区域（M ≈ 0.008、C ≈ 0.01）不在网格内**：p_b = 0 这一列的主指标和次要指标在小 C 下都是 NA。

**外部效度检验不通过（最重要）**：
- 相图预测，Bucket 所在区域（C ≈ 0.055、M ≈ 0.28）应该是有界分布占优（+8% 到 +17%）。
- 实际 Bucket 上有界分布更差（−7% 到 −12%）。
- **这个受控基准漏掉了真实数据中的某个关键因素。** 候选因素包括：真实状态正好等于边界值的点质量（Bucket 上层土壤约 20% 的时间正好为 0）、外生驱动、多维潜变量、动态。这些只是假设，**不能在已看过的数据上确认。**

**对下一步的含义**：
- Gate A 与 Gate B 都只是形式上通过，而且理论反事实全部反向，相图也没能预测 Bucket。
- **进入 Gate C（ASCL）之前**，建议先做一个明确标注为"后续"的补充网格：加入第三个旋钮"正好位于边界值的状态比例"，并补上低 M 的格子。在运行之前单独预注册。
- 这个补充网格只用来寻找控制变量，属于开发证据，不能作为 ASCL 的验证。

### Stage 2 相图：设计预先写定（2026-09-27，运行之前）

**生成器（`scrl/data_phase.py`）**：一维静态潜变量 h°，每个单元有 T = 50 次观测，x_t ~ TN(h°, σ_obs²; [0,1])，取 σ_obs = C·√T，使名义后验标准差为 C。
- 边界单元（比例 p_b）：h° ~ U(0, C)，随机放在上界或下界一侧，即距边界不超过一个名义后验标准差。
- 内部单元：h° ~ U(0.3, 0.7)。
- 目标：y = g(h°)，g 为固定的随机正弦映射，外加 TN 噪声 0.03。
- 规模：训练 5000、校准 2000、测试 2000；每个种子使用各自的 data_seed，使校准/测试集随种子变化。

**网格**：C ∈ {0.005, 0.01, 0.02, 0.05, 0.1, 0.2} × p_b ∈ {0, 0.1, 0.2, 0.4, 0.6, 0.8}，共 36 格。
- 分布族：gaussian、trunc_gaussian、logit_normal、beta、kumaraswamy
- 解码器：TN-hetero
- 每格 5 个种子，共 900 次运行

**指标**：
- 主指标：oracle 分组（真值 h°）、ε = 0.05 下的原始宽度差 ΔW = W_G − W_B，四种有界分布**各画一幅**，不事后挑"最好的那个"。
- 次要指标：截断宽度，ε = 0.10，覆盖率。
- 横轴按设计参数 p_b 排布，同时报告实测 Gaussian 泄漏 M。

**预期**（来自已采纳的计划）：
- C 小、p_b 小（左下）：Gaussian 占优。
- p_b 大、C 大：有界分布占优。
- Kumaraswamy 在 C 小时失败最严重。

**判定"规律存在"**：ΔW 的符号在 ≥ 4/5 个种子上一致的格子能连成片，且符号随 (p_b, C) 单调变化。**否则判定规律未建立，Stage 3 暂缓。**

**Stage 2 设计偏差 1（2026-09-27，查看任何相图结果之前记录）**：p_b = 0 这一列所有单元的真值都在 [0.3, 0.7]，oracle 边界组为空，主指标无定义。这是设计本身的结构性问题，与结果无关。处理：p_b = 0 列只报告观测分组的宽度（次要指标），标注"主指标无定义"；主指标相图只含 p_b ∈ {0.1, 0.2, 0.4, 0.6, 0.8} 五列。

**报告规则**：凡是跑过模型的数据集，结果全部写进论文（正文或附录），不做挑选。某个数据集因数据质量或可得性被弃用时，理由必须在跑模型之前记录在这里。

**主指标**：
- 按与模型无关的观测分组 d(x_T) < ε 做 Mondrian 分组，ε = 0.05 为主；0.025、0.10、0.15 为次要指标。

- C1：Gaussian 模型在边界组上的平均泄漏 ≥ 0.05
- C2：解码器外推比 ‖Δ‖/ρ 的中位数 ≥ 0.1
- C3：分位数临界质量 m(τ = 0.1) > 越过质量 m₋

**预测**：
- C1–C3 都成立时：Gaussian 的边界宽度显著大于 Kumaraswamy。
- C2 不成立时（投影输入解码器），或 C1 不成立时：差距不显著。
- 条件成立但效应不出现，视为理论不成立的证据，照实报告。

**数据集清单**（在可得性核实之后、跑模型之前确定最终版本）：
1. Syn-Full
2. Syn-Extreme
3. Bucket 半合成：CAMELS 气象驱动 + 已知容量的土壤水箱

**修订 2（2026-09-26，跑任何 bucket 模型之前）**：bucket 模拟器的蒸散发改用水分胁迫曲线：相对含水量低于 0.5 时按平方根下降。原来的线性形式会让干燥边界在有限时间内永远达不到，不符合土壤会干到凋萎点的物理事实。这是物理设定，不是根据结果调整。

**修订 3（2026-09-26，跑任何 bucket 模型之前）**：bucket 的气象驱动站点从 CAMELS 流域改为 ResOpsUS 大坝坐标（用固定种子随机抽 120 个），气象数据用 Daymet v4 单点 API，1990–2019 年。理由是可得性：CAMELS 官方下载链接已失效，HydroShare 上的副本是 HDF5 格式，现有环境读不了。驱动数据仍然是真实观测，站点覆盖美国本土各气候区。
**ResOpsUS 库容待定**：数据本身不含库容，只有大坝位置和时间序列。上界必须用工程库容（GRanD 的 CAP_MCM 或美国大坝名录 NID 的库容），**不能用观测到的最大库容**，否则违反"上下界先验已知"的原则。库容来源确定之前不跑 ResOpsUS 模型。

**修订 4（2026-09-26，下载前写定）**：海冰区域定为**哈德逊湾**（北纬 56–63°、西经 94–79°），1990–2019 年日数据，每隔一个 25 km 格点取一个。理由是物理上的：这是完全季节性的冰区，每年都会到达 0% 和接近 100% 两端。观测噪声直接用产品自带的 `cdr_seaice_conc_stdev`。

**修订 5（2026-09-26，查看任何库容数据之前写定）**：ResOpsUS 的上下界。
- **上界** = NID 的 "Max Storage"（坝顶高程对应的库容，是硬性的物理上限）。不用 "Normal Storage"（正常蓄水位库容），因为汛期实测库容可以合法地超过它。**下界** = 0。单位换算：1 英亩·英尺 = 0.0012335 百万立方米。
- **匹配规则**：ResOpsUS 大坝与 NID 按坐标匹配，取 3 km 内最近的 NID 大坝，且坝名首个词相同（忽略大小写）。匹配率要报告。
- **排除规则**：实测库容超过 NID Max Storage 2% 以上的大坝视为元数据不一致，予以排除，并报告数量。
- **单元和划分**：单元 = 一座大坝上一段 180 天的窗口，目标 = 窗口结束后第 7 天的库容；按大坝划分训练组和池组；训练用 1980–2009 年，校准和测试都从池组大坝的 2010–2020 年中独立同分布抽取；regime 取季节（K = 4）。
- **预期**：以坝顶库容为上界，上边界附近的样本可能很少，C1 可能不成立。这种情况下，预测是"效应不显著"，照实报告。

**修订 6（2026-09-27 写定，暂定，待用户确认）**：双通道假设的预注册。写定时，Syn-Extreme 已跑完但结果**尚未查看**；bucket 和 ResOpsUS 还在运行，结果也未查看。

- **H1（尺度通道）**：TN-hetero 主比较中，只要宽度差距不可忽略（|log(W_G/W_K)| > 0.02），差距中来自尺度 σ̂ 的份额 > 50%。
- **H2（分位数通道）**：Gauss-homo 固定解码器比较中，只要宽度差距不可忽略，差距中来自分位数的份额 > 50%。
- **H3（泄漏门控）**：Gaussian 模型在观测边界组上的泄漏越低，差距越小。预测：ResOpsUS 的泄漏最低，其主比较的差距在三个数据集中最小。
- **判定**：三个数据集上 H1、H2 各自至少 2/3 成立，才算支持双通道假设；否则照实报告为不支持。

## 5. 实验日志（按时间追加）

### 2026-09-26：首批单种子结果（Syn-Full，seed 0，只作方向参考，不是结论）
1. **旧设定下 Kumaraswamy 拟合不了数据。** a, b 用 softplus 参数化、上限 50 时，重构项只有 0.10（Gaussian 是 6.69）：在内部区域，它表达不了标准差约 0.02–0.03 的窄后验。改为对数参数化 exp(r)、上限 1e4 后，重构项升到 5.98。旧稿"δ = 1e-3、上限 50"的设定本身会让 SCRL 吃亏。
2. **旧稿的主指标 BIW 有混杂。** 它按各模型自己的后验均值分组，而有界后验的均值到不了边界：即使真实状态恰好在边界上，均值也会落在内侧约一个标准差处。结果 ε = 0.05 时，Kumaraswamy 的边界组只有 176 条轨迹，Gaussian 有 702 条，两者的 BIW 算在不同人群上，不可比。
   → **改用与模型无关的分组作为主指标**：按最后一次观测 x_T 分组（真实数据上也能用），并以真实状态 h° 分组作为 oracle 对照。按各模型自身分组的结果只作为附带报告。
3. **在共同人群（真实边界组）上，区间宽度差不多**：ε = 0.05 时 Gaussian 0.224、Kumaraswamy 0.228、Beta 0.234；ε = 0.1 时有界分布窄 7–9%。
4. **理论检验（Gaussian）**：命题 3 的单侧性严格成立（相对 h* 的 FN = 0，FP ≈ 24%）；但**定理 5 预言的分位数膨胀没有出现**：q^G = 1.23 < q* = 1.30，得分增量的中位数为负，m ≈ 0.006 < m₋ ≈ 0.031。
5. 下一步：跑 10 个种子的完整网格，再看 1–4 条是否稳定。

### 2026-09-26：Syn-Full 10 个种子结果（预注册主检验）
按观测分组、ε = 0.05、TN-hetero 解码器：

| 比较 | Gaussian | Kumaraswamy | 缩小 | Wilcoxon p |
|---|---|---|---|---|
| 主比较 | 0.2104 | 0.2011 | 4.4% | 0.002（10/10 个种子方向一致） |
| 固定解码器（Gauss-homo） | 0.2245 | 0.2186 | 2.6% | 0.11（不显著；oracle 分组下 p = 0.004） |
| 饱和解码器（投影输入） | 0.2067 | 0.2011 | 2.7% | 0.027 |

- **主检验显著，但效应小**：4.4%，远低于旧稿声称的 53%。其他有界分布同样有效，甚至更好（logit-normal 0.1985、Beta 0.2005），说明起作用的是"有界支撑"本身，而不是 Kumaraswamy 这个特定分布。
- 饱和解码器下差距从 4.4% 缩小到 2.7%，**方向符合理论，但没有消失**。
- **理论条件**：C1 成立（泄漏 0.193），C2 成立（‖Δ‖/ρ 中位数 0.52），**C3 不成立**（m = 0.003 < m₋ = 0.026）；在 Gaussian 自身的潜变量边界组上，q^G = 1.24 < q* = 1.30。命题 3 严格成立（相对 h* 的 FN = 0，FP = 24.5%）。
- **按预注册的判定**：效应出现了，但 C3 不成立，说明宽度的缩小**不是通过定理 5 的"分位数膨胀"机制实现的**。机制要另找，可能是归一化尺度 σ̂ 的差异，需要做分解实验。
- **覆盖率**：观测分组下边际覆盖率约 0.889，所有模型都略低于 0.90（1.6 个标准误）。原因是所有种子共用同一套校准/测试数据（data_seed 固定），覆盖率实际上只是一次抽样。**之后的覆盖率检验要让种子同时改变 data_seed。**

### 2026-09-26：海冰 10 个种子结果
观测分组、ε = 0.05（括号中是 ε = 0.10）：

### 2026-09-26：机制分解（探索性，非预注册）
每个组内，平均宽度 = 2 × 分位数 q × 平均尺度 σ̂，所以两模型的宽度比 = 分位数比 × 尺度比（精确成立）。观测分组、ε = 0.05：

| 数据 / 比较 | 宽度比 G/K | 分位数比 | 尺度比 | 差距中来自分位数的份额 |
|---|---|---|---|---|
| Syn-Full 主比较（TN-hetero） | 1.046 | 0.994 | 1.052 | −13% |
| Syn-Full 固定解码器 | 1.027 | 0.976 | 1.052 | −90% |
| 海冰主比较（TN-hetero） | 1.083 | 1.007 | 1.075 | 9% |
| 海冰固定解码器 | 1.547 | 1.481 | 1.044 | 90% |
| 海冰饱和解码器 | 1.120 | 1.144 | 0.979 | 119% |

- **异方差（TN-hetero）解码器下，差距几乎全部来自尺度 σ̂**：泄漏样本经解码器后分散开，总方差中的"样本间"项变大，区间随之变宽。这不是定理 5 的分位数机制。
- **海冰的同方差解码器下，差距主要来自分位数**（90%）：σ̂ 没法把泄漏的影响吸收进去时，影响就体现在得分分位数上，这与定理 5 的机制一致。
- **可能的新理论方向**：泄漏要么抬高归一化尺度，要么抬高得分分位数，走哪条通道取决于得分是否归一化。这是在看到数据之后形成的假设，**必须在新的数据或新的种子上重新检验，不能拿同一批结果既提出又确认**。

### 2026-09-27：ResOpsUS 10 个种子结果（修订 6 写定之后才查看）——与结论相反

### 2026-09-27：总体结论（五个预注册数据集全部完成）
Kumaraswamy 相对 Gaussian，TN-hetero，观测分组，ε = 0.05，原始宽度（正值 = Kumaraswamy 更窄）：

| 数据集 | 泄漏 | 宽度变化 | p |
|---|---|---|---|
| Syn-Full | 0.19 | +4.4% | 0.002 |
| Syn-Extreme | 0.51 | +4.7% | 0.002 |
| 海冰 | 0.79 | +7.8%（截断后 −7.6%） | 0.010 |
| Bucket（半合成，真实气象驱动） | 0.28 | **−7.7%** | 0.002 |
| ResOpsUS | 0.008 | **−100.8%** | 0.002 |

1. **无条件的论断**（"有界潜变量缩小边界区间"）**不成立**：五个数据集中，两个显著反向。
2. **按泄漏门控的条件论断也不成立**：bucket 泄漏高，结果却反向。
3. **定理 5 的机制在五个数据集上都没有得到验证**：C3 全部不成立；q^G > q* 只在 Syn-Extreme 上出现过一次。
4. **成立的部分**：
   - 命题 3（单侧的划分误差）五个数据集都严格成立（FN = 0）。
   - 引理 1、2（Gaussian 泄漏），泄漏在 0.008–0.79 之间。
   - 双通道分解按修订 6 的判定得到支持：H1 3/3，H2 2/3。**但它只描述差距从哪里来，不决定差距的正负**；H3 不成立。
   - Kumaraswamy 的结构性缺陷：内部区域的窄后验表达不了。
5. **旧稿的数字（27–53%、3 倍）在任何数据集上都没有复现。**
6. **五个预注册数据集已全部用完。此后再加的任何数据集都不能用来"挽救"结论**；只能作为新的、另行预注册的研究。
